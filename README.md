## Run locally

This is a static site with HTML, CSS and JavaScript. No package installation or build step is required.

From the repository root, run:

```sh
python -m http.server 8000
```

Open http://localhost:8000. An internet connection is needed for CDN fonts, icons, GSAP animations, embedded project previews and the optional GitHub repository summary. External services may be unavailable or rate-limited.
