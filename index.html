DocuSense AI

Enterprise document intelligence — 100% client-side RAG

The problem: document Q&A tools mean uploading sensitive files to somebody else's server — a non-starter for regulated or confidential documents.

The build: a real retrieval-augmented Q&A pipeline that never leaves the browser — parsing, chunking, embeddings, semantic search and extractive answering, with no API keys and no cloud storage. Ships with role-based retrieval filtering and a live 6-question eval harness reporting recall, confidence and latency.

P/03 Real data · Live

Literacy Gap Analysis

India's state-level education data — honest findings, null result included

The problem: state literacy and gender-gap data sits across government sources in inconsistent formats, with genuine holes (Telangana's 2014 split, missing exam records) that most write-ups quietly paper over.

The build: built on real 2015-16 UDISE school-census data, with a documented derivation for every computed metric and a pytest suite validating each number against an independent manual calculation. Gaps stay documented as gaps instead of zero-filled. I tested whether classroom crowding tracks exam pass rates expecting a clean story — it didn't (r ≈ −0.13), so it's published as a null result rather than reframed until something correlated.

P/04 Machine learning

Backstop

Card-fraud decisioning, graded on the future and priced in euros

The problem: a fraud model has to decide in milliseconds on 0.17% prevalence, and then justify the decision. Almost every published model on this data is graded on a random split — trained on Tuesday, tested on Monday — which flatters it by 0.072 of average precision it will never see in production.

The build: an end-to-end system on 283,726 real transactions. Eleven models compared across expanding time windows, the threshold chosen by expected euro cost under a review-capacity constraint, SHAP reasons on every alert, PSI drift monitoring, and a FastAPI service that answers in 2.1 ms and provably reproduces the offline scores. 65 of 97 frauds caught for one false alarm, avoiding €7,071 of €11,596 exposure — on a window the model had never seen.

PDFly

Free file converter — everything stays on your machine

The problem: every free PDF tool wants your file on their server first, for a task the browser can do by itself.

The build: merge, split, compress, rotate, watermark and AES-128 password-protect PDFs, plus conversion between PDF, Word, PowerPoint, Markdown, plain text and images — all client-side, no upload, no backend, no LibreOffice or Pandoc on a server anywhere. Built on pdf-lib, pdf.js, JSZip and mammoth with no framework or build step.
