P/04 Machine learning

Backstop

Fraud detection built around real-world cost

Fraud detection built for real decisions. Tested 11 models on 283,726 transactions using chronological splits, cost-based thresholds and SHAP explanations. On held-out data, it caught 65 of 97 frauds with one false alarm, avoiding €7,071 in exposure. FastAPI serves scores in 2.1 ms, with drift monitoring built in.
